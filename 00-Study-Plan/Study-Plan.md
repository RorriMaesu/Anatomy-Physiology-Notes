# Study plan

Use the chapter folder matching your actual assignment. Chapters 1–12 contain detailed section notes; Chapters 13–28 contain planning outlines to expand during later assignments. This organization is not a verified course syllabus or a promise that your first class ends at Chapter 12.

## Make six things for each assigned section

| Component | What to write |
|---|---|
| Learning targets | Turn each textbook learning objective into a question. |
| Core explanation | Explain structures, functions, relationships, and sequences in your own words. |
| Comparison | Separate concepts you tend to confuse. |
| Diagram | Draw the relationship; reproduce it with labels hidden. |
| Memory cue | Expand the mnemonic, specify direction, and record exceptions. |
| Retrieval | Answer without looking, check, and correct the specific error. |

For an anatomical structure: name, location, identifying features, connections, function.

For a process: starting condition, stimulus, steps, result, regulation, and the consequence of a failed step.

For a muscle: name, region, origin, insertion, action, and innervation when assigned.

For a hormone: source, release stimulus, target, effect, and feedback.

For a disorder: normal structure or process, what changes, and the functional consequence.

## Study cycle

1. Preview learning objectives, headings, and figure captions.
2. Read one subsection.
3. Close the book and explain what you learned.
4. Build the explanation, comparison, or diagram you need.
5. Check against the textbook and correct omissions.
6. Retrieve the material the next day, several days later, and the following week.
7. Mix older material into each review session.

These intervals are a practical starting schedule, not a universal optimal formula. Research supports retrieval practice and distributed study; useful spacing depends partly on the intended retention interval.

## Lecture exam practice

Ask three levels of question: What is it? How does it work? What changes if a condition or component changes?

Example: identify troponin, explain calcium binding, then predict what happens if the SR cannot release calcium.

## Lab practical practice

1. Label a familiar figure.
2. Repeat with labels hidden.
3. Identify structures in a different view or specimen.
4. Give one distinguishing feature and one function.

For bones, add left/right orientation and articulating partner. For muscles, add action and assigned attachments. For tissues, state the visible evidence supporting the identification.

Use the numbered diagram worksheets alongside their answer keys. The schematics are learning models, not substitutes for real specimens or the textbook's anatomical illustrations.

## Error log

| What I missed | Why I missed it | Corrected explanation |
|---|---|---|
| Cardiac control | Associated striations with voluntary control | Skeletal and cardiac are striated; cardiac is involuntary. |
| ATP in cross-bridge cycle | Mixed up steps | ATP binding causes myosin detachment. |
| Skin layers | Forgot mnemonic direction | Come Let's Get Sun Burned runs superficial to deep. |

Aim to explain and label material correctly on two separate study occasions, including an unfamiliar example. This is a practical mastery target, not a guarantee of an exam score.
