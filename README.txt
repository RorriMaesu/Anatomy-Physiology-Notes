WINDOWS DESKTOP
Download Anatomy_and_Physiology_Notes.zip. Right-click the ZIP and choose Extract All. Use Browse to select your Desktop as the destination. The ZIP already contains the main folder named Anatomy and Physiology Notes. Then open that folder and double-click index.html. If your Desktop is managed by OneDrive, select the Desktop shown in File Explorer rather than guessing a path.

HTML pages are for reading and printing. Markdown (.md) copies are editable text; Notepad or a Markdown editor can open them. PNG diagrams open in image viewers; SVG diagrams open in browsers and vector editors. The .mmd files preserve the two original Mermaid diagrams as editable text. The Anatomy-Atlas folder contains a browser-based study map and 52-region quiz; progress is saved on the current device.

Chapters 1-12 contain detailed notes. Chapters 13-28 contain planning outlines. Your syllabus sets assigned content and deadlines.
