Chapter 12 memory cues

12.1 Basic Structure and Function of the Nervous System

Afferent arrives; efferent exits, relative to the CNS.

Precision check: Somatic activity includes reflexes as well as conscious movement.

12.2 Nervous Tissue

Oligodendrocytes myelinate CNS axons; Schwann cells myelinate peripheral axons.

Precision check: One Schwann cell forms one myelin segment; one oligodendrocyte can myelinate segments on multiple axons.

12.3 The Function of Nervous Tissue

Sense, integrate, respond.

Precision check: Not every motor response waits for conscious perception.

12.4 The Action Potential

Na+ rises; K+ returns the voltage.

Precision check: The Na+/K+ pump maintains gradients over time; it does not directly cause rapid repolarization.

12.5 Communication Between Neurons

Temporal time; spatial separate places. Calcium triggers release; receptors determine response.

Precision check: A transmitter's effect depends on its receptor and target cell.
