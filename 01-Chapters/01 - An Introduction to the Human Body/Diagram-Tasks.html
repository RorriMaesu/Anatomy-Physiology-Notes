Chapter 1 diagram tasks

These are drawing assignments to create while studying. Ready-made labeled and blank schematics are in 02-Diagrams. Use textbook figures for anatomical detail.

1.1 Overview of Anatomy and Physiology

Create a comparison table for anatomy, physiology, gross anatomy, and microscopic anatomy. Add one original example to each. Sketch a thin exchange surface and a thick protective surface.

OpenStax section 1.1

1.2 Structural Organization of the Human Body

Make a six-level ladder using one example that connects to the next, such as protein → muscle cell → cardiac muscle tissue → heart → cardiovascular system → person. Build an 11-row system table.

OpenStax section 1.2

1.3 Functions of Human Life

Create a function–definition–example table. Use protein synthesis for anabolism, glucose breakdown for catabolism, and a stem cell becoming a muscle cell for differentiation. Link each example to an organ system.

OpenStax section 1.3

1.4 Requirements for Human Life

Write four headings: oxygen, nutrients, temperature, pressure. Under each, explain the cellular need and predict a consequence of a major change. Include water under nutrients.

OpenStax section 1.4

1.5 Homeostasis

Draw and label both feedback loops. For temperature regulation identify stimulus, receptor, control center, effector, response, and how the response changes the original stimulus. Add a cold-response branch.

OpenStax section 1.5

1.6 Anatomical Terminology

Draw front and back body outlines, three cutting planes, a cavity map, and a nine-region abdominal grid. Write six complete comparison sentences such as “The elbow is proximal to the wrist.”

OpenStax section 1.6

1.7 Medical Imaging

Make a five-row table for X-ray, CT, MRI, ultrasound, and PET. Record the physical principle and a textbook use. Identify which methods use ionizing radiation.
