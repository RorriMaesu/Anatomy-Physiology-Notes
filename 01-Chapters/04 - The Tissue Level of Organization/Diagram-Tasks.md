# Chapter 4 diagram tasks

These are drawing assignments to create while studying. Ready-made labeled and blank schematics are in 02-Diagrams. Use textbook figures for anatomical detail.

## 4.1 Types of Tissues

Draw a four-tissue concept map. Build a membrane table with tissue composition, location, secretion, and function. Add a three-germ-layer diagram with representative derivatives.

[OpenStax section 4.1](https://openstax.org/books/anatomy-and-physiology-2e/pages/4-1-types-of-tissues)

## 4.2 Epithelial Tissue

Build a slide-identification table for every epithelial type in the section using layers, surface shape, visible clues, location, and function. Draw simple, stratified, pseudostratified, and transitional examples.

[OpenStax section 4.2](https://openstax.org/books/anatomy-and-physiology-2e/pages/4-2-epithelial-tissue)

## 4.3 Connective Tissue Supports and Protects

Build a matrix for areolar, adipose, reticular, dense regular, dense irregular, elastic connective tissue, three cartilages, bone, and blood. Record cells, fiber arrangement, location, and function.

[OpenStax section 4.3](https://openstax.org/books/anatomy-and-physiology-2e/pages/4-3-connective-tissue-supports-and-protects)

## 4.4 Muscle Tissue and Motion

Create a three-row comparison table with shape, nuclei, striations, junctions, control, location, and job. Sketch each type as it would appear in a longitudinal section.

[OpenStax section 4.4](https://openstax.org/books/anatomy-and-physiology-2e/pages/4-4-muscle-tissue-and-motion)

## 4.5 Nervous Tissue Mediates Perception and Response

Draw a neuron and label soma, nucleus, dendrites, axon, and terminals. Place signal-direction arrows. Compare neuron and glial roles and connect a sensory input to a muscle response.

[OpenStax section 4.5](https://openstax.org/books/anatomy-and-physiology-2e/pages/4-5-nervous-tissue-mediates-perception-and-response)

## 4.6 Tissue Injury and Aging

Draw a repair timeline with overlapping phases. Compare regeneration and fibrosis using epidermis and severely injured myocardium. Add normal repair versus uncontrolled growth.

[OpenStax section 4.6](https://openstax.org/books/anatomy-and-physiology-2e/pages/4-6-tissue-injury-and-aging)
